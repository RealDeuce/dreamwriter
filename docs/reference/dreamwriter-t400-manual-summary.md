# DreamWriter T400 Manual Summary

Transcribed from the DreamWriter T400 Instruction Manual (NTS Computer
Systems Ltd, Ver 5.00, 1997). Page numbers reference the original PDF.

## Hardware

- Display: 80 characters x 8 lines LCD (p.3)
- Keyboard: full-size, color-coded keys matching Menu Bar functions (p.3)
- Power: internal rechargeable NiCad batteries, ~8 hours per charge (p.4)
- Lithium battery (CR2032): preserves built-in memory files (p.116)
- Card battery: preserves card memory files (p.117)
- PCMCIA slot: Type 1 SRAM cards, 64 KB to 1 MB (p.4)
- Serial port: for ImageWriter printer, Mac/PC transfer, modem, DreamLink (p.4)
- Parallel port: standard Centronics for IBM-compatible printers (p.4)
- Optional IR port: wireless printing/data transfer via DreamLink (p.4)
- Contrast dial: adjusts LCD brightness (p.5)
- Auto power-off: preset 2 minutes, configurable 3/5/10/15/20/unlimited (p.8)
- Power-on buzzer: 3 types or off (p.9)
- Auto-resume: saves state and restores on power-on (p.8)

## Storage

Three storage types (p.70):
- **Built-in memory**: internal flash/SRAM for files
- **Card memory**: PCMCIA Type 1 SRAM, 64 KB to 1 MB
- **DreamLink**: external devices via serial/IR

TAB key switches between Built-in, Card, and DreamLink directories
during file operations (p.73).

File names: up to 8 characters, no spaces or `*` `?` (p.73).
Directory shows: filename, size (bytes), date (p.73,75).

Files stored as: `SCHEDULE.ODB` (scheduler, p.105), `ADDRESS.ODB`
(address book, p.115).

## World Clock Details (p.106)

- 222 cities worldwide
- Home city + 2nd city simultaneous display
- World map with city position markers
- Options: [H] Set Home City, [2] Set 2nd City, [S] Set Time/Date,
  [F] Display Format (12/24 hour), [A] Daily Alarm
- Date range: January 1, 1980 to December 31, 2079 (p.108)
- Daylight savings time support per city (INS key toggle, p.107)
- 4 daily alarm times with 20-character messages (p.109)
- Alarm sounds for 1 minute regardless of power state (p.110)

## Error Messages (appendix A, p.120)

Referenced in calculator section (p.97):
- OVERFLOW: integer portion exceeded 14 digits
- DIVISION BY ZERO
- OUT OF RANGE: square root of negative number

## Key Hardware Details

- Lithium battery: CR2032 (p.116)
- NiCad: ~4 hours to charge, ~8 hours run time (p.4)
- Right margin at column 136 (p.16)
- Maximum 200 scheduler entries (p.99)
- Maximum 200 address cards (p.111)
- Address card field limits: Name 40, Tel 30, Fax 30, Address 90,
  Memo 100, Salutation 10 (p.112)
- Schedule memo: up to 200 characters (p.101)
